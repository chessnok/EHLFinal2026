## 3. Блок B: общие рычаги переговоров (нужны сессии практики)

### B1. В каждом раунде свежий проверяемый аргумент

Ответы поставщика начиная с раунда 2, когда наш запрос был хотя бы на 5 % ниже его цены (все кейсы кроме P05):

| Что было в нашем письме | Поставщик ответил final offer | Средний шаг | Удержал цену |
|---|---|---|---|
| Проверенный аргумент (n=109) | 4-7 % | 1.3 % | 9 % |
| Без аргумента (n=163) | 53 % | 1.06 % | 58 % |
| Только дубликат (n=16) | 94 % | – | – |

- Арена считает один аргумент на *вид* на кейс, а не на ID. На P07 `fc:360011`, `fc:360012`, `fc:360030` после
  `fc:360010` пришли `duplicate`. Мы убираем повторы по ID (`tactical.py:1250`), поэтому шлём дубликаты раунд за
  раундом.
- Для бандлов нет аргументов по истории заказов: `data.py:302` пропускает кейсы с несколькими деталями, хотя
  `api.md` считает заказы каждой детали отдельным аргументом.
- **Изменение (флаг):** убирать повторы по виду на всех раундах; придерживать один проверенный аргумент на
  раунды 3-4; заказы по каждой детали бандла.

### B2. Падения индексов, которые мы не цитируем

`ledger.recent_drop` берёт только окна, которые кончаются последним месяцем ряда. Арена принимает любое окно до
12 месяцев, кончающееся в последние 12 месяцев. Не процитированы:
- P02: CU-NOTATION −2.2 % (`idx:CU-NOTATION@2026-01` → `@2026-03`), PPI-C241 −2.3 % (2025-06 → 2025-11);
- P08: LCI-C −0.26 % (`idx:LCI-C@2025-10` → `@2026-01`), новый ряд, не дубликат.

**Изменение (флаг):** искать падения по всем допустимым окнам, по одному на ряд.

### B3. Брать более дешёвую альтернативу и при малой экономии

`tactical.py:782` берёт альтернативу поставщика, только если она дешевле на 0.2 % C. На P08 сделка 5.42 с deadband
3 % (C 1,039,278), а в том же final offer был лист 5.46 с deadband 5 % (C 1,037,632): потеря 0.0094 score, во всех
4 сессиях текущего `tactical` на P08. **Изменение:** порог как доля комнаты `C_open − C_best`, а не C; после
округления листа по `term_options` сравнивать и с primary, не только с `c_alt`.
