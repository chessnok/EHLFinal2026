# Параметры сделки и формула стоимости C

Источник: `negotiation-arena-kit/brief/api.md` и `brief/brief.md`. Опубликованная функция — `arena_kit.cost.total_cost`;
наш агент считает через неё.

**Формула одна для всех кейсов, практических и финальных.** Меняются её входные данные: какие поля в кейсе
обсуждаются и какие ставки у покупателя.

## Параметры сделки (term sheet)

| Поле | Что это |
|---|---|
| `unit_price` | цена за единицу в €, 2 знака (за `price_unit` детали: шт., 100 шт., кг) |
| `payment_days` | срок оплаты, дней нетто (0–120) |
| `lead_time_days` | срок поставки от заказа, дней |
| `volume_per_year` | обязательный годовой объём |
| `contract_months` | длительность договора (0–36; 0 — разовый заказ, считается как годовая партия) |
| `effective_date` | дата, с которой действует новая цена |
| `index_clause` | индексная оговорка: цена следует за индексом (серия, доля материала, мёртвая зона, базовый месяц) |
| `incoterm` | `EXW` / `FCA` / `DAP` — кто платит за доставку |
| `tooling_eur` | разовая оплата оснастки |
| `ppm_commitment` | обязательство по браку, ppm |
| `chargeback_eur_per_complaint` | сколько поставщик платит нам за рекламацию |

**Не все поля обсуждаются в каждом кейсе:**

- **`negotiable`** — поля, которые обязаны быть в каждом term sheet. Например, в D02 это цена, оплата, срок поставки и
  Incoterm.
- **`fixed_terms`** — поля, зафиксированные кейсом.
- **Стандартные условия поставщика** из PDF котировки — по ним закрывается всё, что не указано в term sheet и не
  зафиксировано кейсом.
- **`term_options`** — допустимые значения для полей кроме цены.

## Параметры покупателя (свои в каждом кейсе, блок `buyer`)

| Параметр | Что это |
|---|---|
| `need_per_year`, `horizon_years` | сколько нужно в год и на сколько лет (не больше 3) |
| `current_unit_price` | цена до вступления новой |
| `fallback_unit_price` | цена непокрытой потребности: перетендер или спот |
| `interest_rate`, `reference_payment_days` | стоимость денег и наш стандартный срок оплаты |
| `need_lead_time_days`, `late_cost_per_day` | нужный срок поставки и штраф за день сверх него |
| `cost_per_defect` | цена одного дефекта |
| `category_goal` | `stabilise`, `secure_supply`, `quality_first`, `leverage` или `routine` — задаёт ставки ниже |
| `fallback_risk_pct`, `index_risk_pct` | риск непокрытой потребности и риск индексной оговорки, в % |
| `sustainable_margin_pct`, `relationship_eur_per_point` | только `stabilise` и `secure_supply`: устойчивая маржа поставщика и штраф за каждый пункт ниже неё |
| `freight_eur_per_unit` | доставка за единицу по каждому Incoterm |
| `index_paths` | ожидаемое движение индексов за горизонт |
| `must_haves` | обязательные условия: нарушил — скор 0 |
| `alternative` | что получаем без сделки |

## Формула полной стоимости C

Обозначения: `N` — `need_per_year`, `H` — `horizon_years`, `V` — `volume_per_year`, `M` — `contract_months`,
`P` — `unit_price`, `r` — `interest_rate`, `d_ref` — `reference_payment_days`.

```
years     = min(M / 12, H); разовый заказ (M = 0) = 1 год
committed = V · years                         купили, нужно или нет
covered   = min(V, N) · years
pre       = единицы до effective_date (по current_unit_price)
new       = (committed − pre) · P
spend     = pre · current_unit_price + new
uncovered = (N · H − covered) · fallback_unit_price

C = spend
  + uncovered · (1 + fallback_risk_pct / 100)                      непокрытая потребность и её риск
  + spend · r · (d_ref − payment_days) / 360                       ранняя оплата стоит процентов
  + committed · freight_eur_per_unit[incoterm]                     доставка
  + late_cost_per_day · max(0, lead_time_days − need_lead_time_days)
  + committed · ppm_commitment / 1e6 · (cost_per_defect − min(chargeback, cost_per_defect))
  + tooling_eur
  + new · material_share · max(0, |index_path| − deadband/100) · sign(index_path)   с индексной оговоркой
  + new · material_share · index_risk_pct / 100                                     с индексной оговоркой
  + relationship_eur_per_point · soft(sustainable_margin − маржа поставщика) · years  только stabilise / secure_supply

soft(g) = 0 при g ≤ 0;  g² / 10 при 0 < g ≤ 5;  g − 2.5 при g > 5
```

Горизонт начинается с зафиксированной или самой ранней допустимой `effective_date`; `index_path` — ожидаемое движение
серии из оговорки за горизонт.

**Маржа поставщика** = `(value − full_cost) / value × 100`. Здесь `value` — сколько сделка реально стоит для него в
деньгах за единицу, с учётом сроков оплаты, доставки и оснастки. Его себестоимость `full_cost` нам неизвестна, её
приходится оценивать, например по should-cost.

## Скор

```
score = clip((C_open − C_deal) / (C_open − C_best), 0, 1)
```

- **`C_open`** — самое дешёвое открывающее предложение, соблюдающее must-haves.
- **`C_best`** — меньшее из двух: наша альтернатива или лучший пакет, на который согласился бы хоть один поставщик при
  всех валидных рычагах. Он фиксирован заранее, поэтому хорошие аргументы поднимают скор, а не сдвигают планку.
- **Без сделки** — скор альтернативы (0, если её нет).
- **Нарушено обязательное условие** — 0.
- **Финал:** волна даёт среднее по кейсам × 100, очки суммируются по 5 волнам, максимум 500.

## Что одинаково, а что меняется

**Одинаково:** формула C и скор. В брифе прямо сказано, что правила расчёта одинаковы для практики и скрытых кейсов
финала.

**Меняется от кейса к кейсу:**

- **Обсуждаемые поля и допустимые значения** (`negotiable`, `term_options`, `fixed_terms`).
- **Все ставки покупателя.** Их определяет `category_goal`: например, штраф за маржу поставщика есть только в
  `stabilise` и `secure_supply`, а у `leverage` выше риск непокрытой потребности.
- **Стандартные условия поставщика** из PDF котировки: по ним закрывается всё, что не указано в term sheet.

Поэтому одна и та же цена может давать очень разную C. На D01 разница между договором на 12 и на 24 месяца составила
около 30 тыс. € при почти одинаковой цене за штуку: с коротким договором второй год горизонта покупается по
fallback-цене.

**Цель покупателя — минимальная C, а не минимальная цена.** Иногда выгоднее чуть более высокая цена с лучшей
структурой. Исключение: в кейсах `stabilise` и `secure_supply` C штрафует за маржу поставщика ниже устойчивой, поэтому
слишком сильно продавливать цену тоже невыгодно.
